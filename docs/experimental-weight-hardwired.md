# 实验性方案: 权重硬化 (Weight-Hardwired) AI 加速器

> **状态**: 🔬 实验性 (未实现, 概念验证阶段)
> **日期**: 2026-08-28
> **动机**: 解决 128×128 XNOR 阵列的存储带宽瓶颈 (500 GB/s 需求 vs 实际 ~32 GB/s)

## 核心思想

BNN 权重只有 ±1。把权重**烧死在晶体管连接里**, 彻底消灭权重存储与读取:

```
权重 = +1 → XNOR(a, 1) = a         (直通, 0 门)
权重 = -1 → XNOR(a, 0) = NOT a     (1 个反相器)

普通 XNOR: 1 XOR + 1 NOT = 2 门
硬化 XNOR: 权重固定后 0~1 门 (面积减半)
```

## 为什么是实验性

| 优势 | 代价 |
|------|------|
| 带宽需求降 16× (只喂激活) | **模型永固化** — 流片后不能改权重 |
| 面积减半 (~16000 门 @128×128) | 一个芯片只能跑一个模型 |
| 功耗更低 (纯逻辑) | 改模型 = 重新流片 |
| 无存储瓶颈 (32 GB/s 足够) | 不通用 (专用芯片) |

## 带宽对比

| 方案 | 每 cycle 喂数据 | @250MHz 带宽 |
|------|---------------|-------------|
| 128×128 可配置权重 (v0.4) | 128bit 激活 + 16384bit 权重 | 500 GB/s 💀 |
| **128×128 权重硬化** | **128bit 激活** | **32 GB/s ✅** |

## 面积对比

| 阵列 | 可配置 (v0.4) | 权重硬化 |
|------|-------------|---------|
| 64×64 | ~8000 门 | ~4000 门 |
| 128×128 | ~33000 门 | ~16000 门 |

## 与存内计算的关系

```
忆阻器/存内计算 (学术前沿): 权重存在物理器件里
咱们的数字版: 权重烧在晶体管连接里 (更可靠, 可综合可验证)

共同点: 计算发生在存储处, 数据不用搬 → 打破冯诺依曼瓶颈
```

## 实现路径 (如果推进)

1. **权重表生成器**: 训练 BNN → 量化 → 输出权重表 (±1 矩阵)
2. **RTL 生成器**: 权重表 → 自动生成硬编码 Verilog (Python 脚本生成电路)
3. **验证**: 生成的电路仿真 vs 软件层对照
4. **流片**: TinyTapeout (模型锁死版, 一个模型一颗芯片)

## 适合场景

- ✅ 固定任务专用: 手势识别 / 固定目标检测 / 唤醒词
- ✅ 量产定制: 一个芯片一个模型, 批量生产
- ❌ 通用 AI: 需要可配置权重 (走 v0.4 路线)
