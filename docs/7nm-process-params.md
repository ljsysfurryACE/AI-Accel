# 7nm 工艺参数基准 (F 系列极限版)

> AI-Accel F 系列 · 7nm 工艺参数
> 数据: 公开文献/行业经验 (7nm FinFET)

## 1. 核心工艺参数

| 参数 | 值 | 说明 |
|------|-----|------|
| NAND2 面积 (GE) | **0.2 μm²** | 7nm 标准单元 |
| FO4 延迟 | **5-8 ps** | 7nm FinFET |
| 逻辑密度 | ~1000-1500万门/mm² | 理论 |
| 布图利用率 | 70% | |
| Vdd | **0.7-0.8V** | |
| SRAM bit | ~0.045 μm² | 高密度 |
| 频率潜力 | **3-5 GHz** | 短关键路径 |

## 2. 折算规则

```
面积: GE × 0.2μm² / 0.70
时序: 2FO4/级, 3GHz = 333ps ≈ 50 FO4
功耗: 动态 ∝ C·V²·f (V=0.75V)
```

## 3. BF16 浮点单元面积 (估算)

| 单元 | 门数 | 说明 |
|------|------|------|
| BF16 乘法器 | ~300-500 门 | 7×7 尾数 + 指数 |
| FP32 加法器 | ~2000-3000 门 | 对齐+归一化 |
| **每 MAC** | **~2500-3500 门** | 乘+加 |
| vs BNN XNOR | 2 门 | 差 ~1500 倍 (精度代价) |

## 4. 7nm 极限规格 (yosys 实测外推)

**8×8 实测: 382,000 cells ≈ 19 万 GE ≈ 0.055 mm² (每 MAC ≈ 6000 cells)**

| 配置 | MAC 数 | 面积 @7nm | 算力 @3GHz |
|------|--------|----------|-----------|
| 16×16 | 256 | ~0.22mm² | 768 GFLOPs |
| 32×32 | 1024 | ~0.88mm² | **3 TFLOPs** |
| 64×64 | 4096 | ~3.5mm² | 12 TFLOPs |
| 128×128 | 16384 | ~14mm² | **49 TFLOPs** |

## 5. 对比

| 方案 | 算力 | 精度 |
|------|------|------|
| F 7nm 128×128 | 49 TFLOPs | **FP16 真浮点** |
| C 28nm BNN 128×128 | 4.1 TOPS | XNOR 位级 |
| 骁龙 8 Gen2 NPU | ~30 TOPS | INT8 |
| A17 NPU | ~35 TOPS | INT8/FP16 |
