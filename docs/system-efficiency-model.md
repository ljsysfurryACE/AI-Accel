# C 版设计文档：系统能效模型与验收指标

> AI-Accel C 版（28nm 极限版）· 架构基准
> 日期: 2026-08-29
> 定位: 不流片，榨干 28nm 极限，但**以系统能效为最终验收标准**（不是峰值算力）

---

## 1. 核心原则（血泪教训）

**峰值能效 ≠ 系统能效。** 芯片真实的能效由整条链路决定：

```
峰值口径: 阵列全满 + 数据免费 + 利用率 100% → 好看但骗人
系统口径: 数据搬运 + 权重加载 + 空闲等待 + 控制开销 → 真实水平
```

**C 版验收只认系统口径。**

---

## 2. 系统能效模型

### 2.1 有效算力公式

```
有效算力 = 峰值算力 × 利用率 × (1 - 权重加载占比) × (1 - 流水气泡)

峰值算力: 4 核 × 512×512 XNOR @2GHz = 2.1 POPS
利用率:   卷积 ~85%, 非卷积 BNN 空转 → 综合 ~57% (纯 BNN 同构)
权重加载: 每层换权重 → 时间占比 10-25%
流水气泡: 层间切换/屏障/任务间隙 5-10%
```

### 2.2 系统功耗构成

```
计算域:   4 核 @2GHz (组合动态 + FF 时钟, 权重门控后 ~0.9W/核)
数据通路: L2 SRAM 搬运 + NoC/DMA 传输 (实际带宽高于峰值假设)
权重重载: 每层 1Mb 写入 4 核的翻转功耗
控制域:   CPU + 调度器 + 空闲漏电
```

### 2.3 基准数字（三档）

| 口径 | 有效算力 | 总功耗 | 系统能效 (XNOR) | 等效 INT8 |
|------|---------|--------|----------------|-----------|
| **峰值（理想）** | 2.1 POPS | 4.2W | 500 TOPS/W | ~25-50 |
| **系统（诚实）** | ~0.94 POPS | ~5.7W | **165 TOPS/W** | ~8-16 |
| **优化后（目标）** | ~1.6 POPS | ~4.8W | **330 TOPS/W** | ~16-33 |

**落差真相：能效掉 3 倍，算力掉 55%——这就是"考虑整体"的代价。**

## 3. 三大命门与解法（C 版架构驱动力）

### 命门 1：利用率 57%（算力腰斩的元凶）

- **问题**：全连接/池化/后处理时 BNN 阵列空转
- **解法**：**异构并行** —— BNN 核算卷积时，MAC 核算 FC、向量核算池化
- **目标**：利用率 57% → 80%+

### 命门 2：权重加载（时间+功耗双杀）

- **问题**：每层换权重 = 重载 + 重翻转，小模型尤甚
- **解法**：**权重常驻** —— BNN 权重 1-bit，256Kb/核可驻留多层，L2 分层缓存
- **目标**：加载占比 15% → 3%

### 命门 3：数据搬运（功耗被传输吃掉）

- **问题**：激活/结果频繁回 L2，NoC 布线疯狂翻转
- **解法**：**数据就地化** —— 激活就地消费、结果就地累加、少回 L2
- **目标**：搬运功耗 1.5W → 0.8W

## 4. 验收指标（每个 C 子版本必须报告）

### 4.1 必须报告的三项

| 指标 | 定义 | 测量方法 |
|------|------|---------|
| **阵列利用率** | 有效 XNOR / (阵列能力 × 时间) | 计数器 + 周期统计 |
| **系统能效** | 有效算力 / 总功耗 | 功耗模型 + 仿真活动统计 |
| **有效算力** | 实测完成推理量 / 时间 | 端到端推理计时 |

### 4.2 各版本目标

```
C1 (单核 512×512 流水):   验证峰值算力 524 TOPS/核 + 时序
C2 (popcount 树形化):     每级 <170ps, 2GHz 时序收敛
C3 (4 核 + 权重常驻):     利用率 ≥ 70%, 权重重载 ≤ 5%
C4 (异构: BNN+MAC+向量):  利用率 ≥ 80%, 系统能效 ≥ 250 TOPS/W
C5 (端到端真实 CNN):      系统能效 ≥ 300 TOPS/W (优化目标 330)
```

### 4.3 一票否决红线

- 系统能效低于 150 TOPS/W → 架构回炉（不许拿峰值数字凑数）
- 阵列利用率低于 60%（C4 后）→ 并行策略失败
- 权重加载占比高于 10% → 存储层次设计失败

## 5. 功耗模型参数（28nm 基准）

```
Vdd = 0.9V (可 DVFS 至 0.75V)
门负载电容 = 0.5 fF (含布线)
FF 时钟电容 = 1 fF
组合逻辑平均翻转率 α = 0.3 (XNOR 阵列 0.5)
L2 SRAM 访问能量 = 0.2 fJ/bit
时钟门控: 权重锁存推理时停钟 (省 ~1.7W/4核)
```

## 6. 附：为什么 BNN 仍有价值（系统级）

即使系统能效从 500 掉到 165 TOPS/W（XNOR 口径）：
- 等效 INT8 8-16 TOPS/W，**仍高于 4nm 旗舰 NPU**（~10-20，同代际碾压）
- 且这是 **28nm 老工艺** vs 对手 3-4nm
- 每操作能量（XNOR ~0.3fJ vs INT8 MAC ~5-10fJ）是物理级优势，与工艺无关

**一句话：系统能效 165 起步，优化目标 330，这是 C 版每一次提交都要回答的数字。**
